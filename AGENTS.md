# Правила для агентов

## Коммиты
- Коммитить **атомарно**: один логический юнит = один коммит (отдельная фича/дока/файс,
  фиксы отдельно от фич, контент-JSON отдельно от кода, ренейм+правки не смешивать).
- Никогда не коммитить чужие незакоммиченные правки и не использовать `git add -A`.
- Формат: `type(scope): summary` (`feat(combat): …`, `docs: …`, `fix(dialog): …`),
  тело — буллеты что/зачем, если не очевидно из сабжа.
- Каждый слайс/фаза работы субагента заканчивается своим коммитом; результат одного
  коммита должен собираться/запускаться без остальных.

## Ченджолог
- Каждый коммит, меняющий поведение/контент/доки, сопровождается записью в
  `CHANGELOG.md`.
- Формат: группы по датам (новые сверху), без версий и `[Unreleased]`;
  внутри дня записи с маркером `[+]` добавлено / `[~]` изменено / `[!]` исправлено.
  Чистый текст без markdown: файл показывается в игре как есть (`?raw`).
- Запись добавляется тем же атомарным коммитом, что и само изменение, либо сразу
  следующим за ним — не откладывается «на потом».
