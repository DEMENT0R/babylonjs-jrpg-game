# babylonjs-jrpg-game

Пошаговая JRPG в современной реальности: обычный человек (интерн / студент / инженер),
повседневная рутина которой постепенно ломается катаклизмом. Babylon.js + TypeScript + Vite,
первая версия публикуется на GitHub Pages, бэк — потом (контракты заложены заранее).

- Дизайн игры: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)
- Техплан и нарезка на задачи: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
