# babylonjs-jrpg-game

Пошаговая JRPG в современной реальности: обычный человек (интерн / студент / инженер),
повседневная рутина которой постепенно ломается катаклизмом. Babylon.js + TypeScript + Vite,
первая версия публикуется на GitHub Pages, бэк — потом (контракты заложены заранее).

- Дизайн игры: [`docs/GAME_DESIGN.md`](docs/GAME_DESIGN.md)
- Техплан и нарезка на задачи: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- Схемы контента и сейва: [`docs/CONTENT_SCHEMAS.md`](docs/CONTENT_SCHEMAS.md)
- Нарративная библия: [`docs/NARRATIVE_BIBLE.md`](docs/NARRATIVE_BIBLE.md)
- Межслайсовые контракты: [`docs/CONTRACTS.md`](docs/CONTRACTS.md)

## Управление

| Действие | Клавиатура | Геймпад | Смартфон |
|---|---|---|---|
| Ходьба | WASD / стрелки | DPad / левый стик | виртуальный стик |
| Подтвердить / говорить | E / Enter | A / Cross | ◆ |
| Меню / закрыть | Esc | Start / Back, B — закрыть | ☰, тап по реплике |
| Бег | Shift | LB / RB / LT / RT | «Бег» |
| Выбор в меню/бою | стрелки, Enter | DPad / стик, A | тап |

Тач-панель включается на устройствах с грубым указателем; принудительно —
`?touch=1`, отключить — `?touch=0`.
