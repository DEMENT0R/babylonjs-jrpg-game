# JRPG «Обычный день» — Game Design (кратко)

## 1. Концепция
JRPG в **нашей реальности**: современный город, современный быт. Герой — обычный человек
(на выбор: интерн-медик, студент, инженер ЖЭКа). Первый акт — рутина без боёв: лекции,
смены, соседские просьбы, покупки. Затем локальный катаклизм (эпидемия → перебои →
эскалация до войны/карантина) постепенно **искажает те же самые локации, люди и механики**,
пока повседневные навыки не становятся навыками выживания.

Ключевой эффект: игрок узнаёт мир «до», поэтому удар «после» чувствуется. Никакой магии
и фэнтези — только реализм, деградация инфраструктуры и человеческие решения.

## 2. Столпы
1. **Преемственность**: одни и те же локации/НПС в 3 состояниях (норма / кризис / война).
2. **Рутина как прокачка**: действия акта 0 (учёба, готовка, ремонт) дают реальные статы,
   которые определяют выживание в актах 1–2.
3. **Выбор под давлением**: JRPG-дилеммы без «правильного» ответа (отдать лекарства /
   продать / оставить семье).
4. **Пошаговость**: классический turn-based бой, враги эволюционируют от хулиганов до мародёров.

## 3. Акт структура
| Акт | Мир | Геймплей |
|---|---|---|
| 0 «Обычный день» | Нормальный город, 3 дня рутины | Только диалоги, квесты-поручения, статы, время суток |
| 1 «Тревога» | Слухи, скупка товаров, первые перебои | Первые стычки (хулиганы), крафт из бытовой химии |
| 2 «Кризис» | Карантин, пустые полки, патрули | Пошаговые бои, партия из знакомых НПС акта 0 |
| 3 «Война» | Разрушенные версии тех же локаций | Полноценный JRPG-луп: бой, лут, босс-гуманоиды |

Формальный маркер перехода — флаг `worldPhase` (0–3) в состоянии игры; он же переключает
внешний вид локаций, диалоги и таблицы врагов.

## 4. Протагонист (выбор в начале, влияет только на старт)
- **Интерн**: +медицина (лечит партию лучше), старт в больнице, знает врача-наставника.
- **Студент**: +обучаемость (быстрее качается), старт в общаге, сеть знакомых.
- **Слесарь/инженер**: +ремонт и крафт, старт в подвале-мастерской.

В актах 1+ ветки сходятся; происхождение даёт 1 уникальный навык и разные стартовые связи.

## 5. Ядро механик
- **Время**: дискретные слоты (утро/день/вечер). Действие тратит слот; квесты имеют окна.
- **Статы**: Здоровье, Ресурс (мoral/энергия — общий пул на действия), Навыки
  (медицина/ремонт/убеждение/скрытность — качаются использованием).
- **Бой**: turn-based, сторона-против-стороны, очереди по инициативе. Скиллзависимость:
  медицина = хил, ремонт = щит/ловушки, убеждение = шанс избежать боя вовсе.
- **Инвентарь/крафт**: предметы реального мира (аптечка, изолента, сода, генератор).
- **Партия**: 1–3 соратника, все — НПС, знакомые по акту 0; лояльность зависит от выборов.
- **Сохранения**: слоты локально, экспорт/импорт JSON-файлом (важно для GitHub Pages).

## 6. Не-цели (v1)
Никакого бэка, мультиплеера, озвучки, открытого мира. 1 район города, 6–8 локаций,
2–4 часа контента до конца акта 2. Это вертикальный срез, а не вся игра.
