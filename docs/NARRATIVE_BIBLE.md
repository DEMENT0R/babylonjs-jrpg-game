# Нарративная библия (v1, контент слайса 7)

Сеттинг: **Старогорск**, областной город ~300 тыс., наши дни. Игрок видит один спальный
район. Стиль: документальная проза без мистики; катаклизм остаётся за кадром — только его
отражение в городе, ценах, знакомых лицах.

## Катаклизм: эпидемия → карантин → военное положение
| worldPhase | Дни | Город |
|---|---|---|
| 0 | 1–3 | Обычность. «Новый грипп» мелькает фоном в новостях. |
| 1 | 4–7 | ОРС-7 признан опасным: скупка лекарств, закрытие школ, тревога. |
| 2 | 8–14 | Карантин: патрули, талоны, перебои света/воды, сектор поделён на зоны. |
| 3 | 15+ | Военное положение, бои за контроль над районом. **Вне v1.** |

Триггеры фаз — только эффект `setWorldPhase` из квестов (см. `CONTENT_SCHEMAS.md`):
- **0→1** — завершение `q-day3-end` (ужин с соседями + итоговый эфир новостей).
- **1→2** — завершение/провал `q-hospital-panic` (переполнение больницы).
- **2→3** — вне v1.

## Локации (7, у каждой варианты по worldPhase)
1. `apartment` — квартира героя. Ф0 быт → Ф2 укрытие и запасы.
2. `hospital` — городская больница. Ф0 смены → Ф2 переполнена и закрыта.
3. `campus` — универ/общага. Ф0 пары → Ф2 эвакуационный пункт.
4. `pharmacy` — аптека. Ф0 очереди из-за слухов → Ф1 пустые полки → Ф2 разграблена.
5. `square` — двор/площадь района. Ф0 бабушки и дети → Ф2 баррикады.
6. `workshop` — подвал-мастерская. Крафт-хаб, слабо меняется по фазам.
7. `metro-station` — станция метро. Ф0–1 «закрыта на ремонт» → Ф2 бомбоубежище.

## НПС и партия
- **Борис** — наставник-врач. Ф0 советы → Ф1 просит достать медикаменты → Ф2 остаётся в
  больнице (дилемма «уйти/остаться помочь»).
- **Люда** — соседка-пенсионерка. Ф0 квест на лекарства → Ф2 источник рецептов крафта.
  Кандидат в партию (крафтер).
- **Дима** — сокурсник/медбрат. Кандидат в партию (стойкость); Ф1 паникует, лояльность
  зависит от выборов игрока.
- **Зина** — аптекарша. Ф0 ворчливая → Ф1 спекулирует → Ф2 ушла из города.
- **Сергей** — участковый. Ф0 дружелюбен → Ф1 жёстче (облавы) → Ф2 конфликт с мародёром
  **«Клещ»** (мини-босс v1).

## Квесты акта 0 (каждый день = слоты утро/день/вечер)
- День 1 (все): осмотреться дома; поручение стартового НПС по бэкграунду.
- `q-intern-shift` (интерн): принять 3 пациентов; выбор «уйти пораньше / остаться»
  тратит ресурс.
- `q-luda-meds` (все): купить Люде таблетки до вечера — знакомит с аптекой и очередями.
- `q-pipe-burst` (инженер): починить прорыв в подвале — первый крафт-материал.
- День 3: `q-day3-end` — ужин с соседями, эфир новостей → переход в фазу 1.

## Дилеммы (тон: без правильных ответов)
- Последнее лекарство — Люде или себе/семье (лояльность vs выживание).
- Сообщить участковому о спекуляции Зины или закрыть глаза (соц. капитал vs доступ
  к аптеке).
- Провал квеста — не game over, а худшие стартовые условия следующей фазы.

## Акт 1 — верхняя граница контента v1
Слухи и скупка, `q-hospital-panic`: доставка медикаментов со склада (первый бой —
хулиганы у склада). Финал среза — вход в карантин (Ф2), полный акт 2 и акт 3 вне v1.

## Ассеты (политика v1)
До M4 — только примитивы Babylon (box/capsule/cylinder) с перекраской по фазе; НПС =
капсула с цветом роли, мебель — боксы. Внешние паки (Kenney CC0 и т.п.) не подключать
до конца среза; после — отдельный слайс с файлом `docs/ASSET_LICENSES.md`.
